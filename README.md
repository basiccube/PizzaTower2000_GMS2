# Pizza Tower 2000 - GMS2 Edition

Pizza Tower 2000, brought over from GameMaker 6 to the latest version of GameMaker.  
Meant to be used with [Butterscotch](https://github.com/ButterscotchRunner/Butterscotch).

## Things To Note

* Very buggy and not yet finished (this applies to both the game itself and also when running via Butterscotch)
* Code is a mess, needs to be cleaned up a ton
* At this point just launch the actual game using Butterscotch lol

Open the project using GameMaker-LTS 2026, for running on other platforms that aren't supported by the GMS2 runner (like Windows 98, 2000 or XP, etc.), use Butterscotch. Figure out how to compile it or how to get the binary by yourself.
